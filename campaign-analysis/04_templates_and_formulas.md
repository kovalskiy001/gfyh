# Шаблони, формули, чеклісти

## 1. Таблиця щоденного трекінгу (Google Sheets)

Імпортуй [tracker_template.csv](tracker_template.csv) (Файл → Імпорт) і встав формули в рядок 2, далі протягни вниз.

| Кол. | Поле | Як заповнювати / формула (рядок 2) |
|---|---|---|
| A | Дата | вручну |
| B | Гео | HU / SK / ES / IT / SI / HR |
| C | Кабінет | назва або номер кабінету |
| D | ID РК | наприклад 19790 |
| E | ID крео | наприклад 324 |
| F | Тип крео | робоче / унік / нове |
| G | Бюджет на день | 40 |
| H | Спенд (з кабінету) | вручну |
| I | Комісія поповнення | частка: 0.05 = 5% |
| J | Реальний спенд | `=H2*(1+I2)` |
| K | Ліди | вручну |
| L | CPL | `=IFERROR(J2/K2;"")` |
| M | Апрувнуті | з CRM / партнерки |
| N | Апрув % | `=IFERROR(M2/K2;"")` |
| O | Ціна апрува | `=IFERROR(J2/M2;"")` |
| P | Payout | ставка за апрув |
| Q | Дохід | `=M2*P2` |
| R | Профіт | `=Q2-J2` |
| S | ROI | `=IFERROR(R2/J2;"")` |
| T | Зона | `=IF(S2="";"";IF(S2>=0.5;"🟢 масштаб";IF(S2>=0.2;"🟡 тримати";IF(S2>=0;"⚪ мікроплюс";"🔴 мінус"))))` |
| U | Рішення | STOP / ТРИМАТИ / МАСШТАБ / ДУБЛЬ |
| V | Гіпотеза / причина | коротко, своїми словами |

> У Google Sheets з українською локаллю аргументи формул розділяються крапкою з комою `;`, як у таблиці.
> Якщо локаль англійська — заміни `;` на `,`.

**Зведені таблиці (Дані → Зведена таблиця)** — побудуй три і переглядай щоранку:
1. Рядки: Гео; значення: SUM Реальний спенд, SUM Ліди, SUM Апрувнуті, SUM Профіт → ROI і апрув по гео.
2. Рядки: ID крео; ті самі значення → які крео тягнуть, які зливають (одразу видно «унік» проти «робочих»).
3. Рядки: Кабінет; ті самі значення → чи немає «хворого» кабінету.

Фільтр по даті: «останні 3 дні» і «з початку місяця», щоб бачити свіжий тренд, а не лише місячну середню.

## 3. Швидкі розрахунки «в голові»

- **Ціна апрува = CPL / апрув.** CPL $6 при апруві 27% → $22.2 за апрув. При апруві 20% → $30.
- **Беззбитковий CPL = Payout × апрув.** Payout $30 × 27% = $8.10 (з комісією 5% → $7.71).
- **Скільки дадуть 4 нові РК:** 4 × $40 = $160 → при CPL $6 ≈ 26 лідів → при апруві 27% ≈ 7 апрувів на день.
- **«Близько нуля»:** +3% в кабінеті при комісії 5% → реально −1.9%. Плюс вартість акаунтів і проксі.
- **Робоча зв'язка:** 76 конверсій / 6 днів ≈ 13 на день.

## 4. Чекліст перед запуском РК

- [ ] Нових РК сьогодні не більше ліміту (≤ 25% від активних).
- [ ] Гео дня одне; вибране за профітом за 3 дні і вільною капою.
- [ ] Крео — з робочої зв'язки (не власна унікалізація, якщо це не окремий контрольований тест).
- [ ] Кабінет живий, оплата / поповнення ок, на кабінеті немає обмежень.
- [ ] Бюджет на РК — стандартний (~$40).
- [ ] У посиланні проставлені саб-айді: `sub1=кабінет`, `sub2=ID РК`, `sub3=ID крео`.
- [ ] У журналі записані гіпотеза, критерій стопу і час перегляду.
- [ ] Через 2–4 год після запуску — перевірка модерації і спенду (нагадування поставлене).

## 5. Чекліст ранкового зрізу

- [ ] Статистика: вчора / 3 дні / місяць; розріз гео → РК → крео → кабінет.
- [ ] Апрув з CRM по саб-айді.
- [ ] ROI реальний (з комісією).
- [ ] Кожна РК → зона → рішення (STOP / ТРИМАТИ / МАСШТАБ).
- [ ] Вимкнуто все червоне і все «мікроплюсове» без плану.
- [ ] Визначено гео дня і кількість запусків.
- [ ] Перевірено капу: де вибирається повністю — запит на додаткову.
