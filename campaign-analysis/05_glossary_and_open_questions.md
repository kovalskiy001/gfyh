# Словник розшифровки транскрипту і відкриті питання

## 1. Як читати транскрипт: спотворені слова

TurboScribe розпізнав мову і переклав на англійську, тому сленг арбітражу поплив. Ось відповідність:

| У транскрипті | Що означає | Приклад з тексту |
|---|---|---|
| companies | кампанії (РК) | «22 companies, 6 of them new» |
| RR | РК (рекламні кампанії) | «Your RR works according to the principle» |
| IEO | ROI (у більшості місць) або ГЕО | «32 IEOs in Hungary» = ROI ~32% [?]; «test IEO or an offer» = тестове гео або оффер |
| ice / price of ice | ліди / ціна ліда (CPL) | «You only have 4 ice there»; «Good price of ice» |
| CREO / cryo / creos | креатив(и) | «old CREO», «6 creos» |
| unicalization | унікалізація креативів | «I did the unicalization» |
| connection / bunch / setup / stack | зв'язка (оффер + крео + підхід) | «working bunch», «pour these connections» |
| advertising office | рекламний кабінет | «5, 6, 7 advertising offices» |
| drop / cup | капа | «Spain has a big drop»; «Take another cup and start» |
| inflate / flood / pour / drop (companies) | заливати / запускати РК | «inflate every day», «drop 2–3 companies every day» |
| approval / approved / proof | апрув | «Approved 27%»; «gorgeous proof» |
| breathes | «дихає» — живе, конвертить | «790 definitely breathes» |
| fucked up | злив | «All the others are just fucked up» |
| season | созвон [?] | «just before our season» = перед нашим созвоном |
| short cut | зріз статистики | «I made a short cut» |
| It's called a turn | «ось це поворот» — несподіване просідання | про Угорщину |
| go through the bay | «йти через день / щодня» [?] | «I'd drop 2–3 companies every day» |
| Antik | антидетект-браузер | «add the account to Antik in the proxy» |
| TREP | [?] джерело готових робочих крео (спай / командна база / інше) | «everything you took from TREP worked out» |
| P2P money | поповнення через P2P (з комісією) | «commission of payment, P2P money» |
| PT | ймовірно Португалія | «Something on PT» |
| set move | [?] системний / щоденний крок | «If you do a set move every day» |
| 197.53% / 197.90% | ID кампаній 19753 / 19790 (не відсотки) | |

**Порада на майбутнє:** транскрибуй **мовою оригіналу, без перекладу**, і весь файл, а не перші 30 хвилин
(розбити запис на частини по 30 хв або взяти тариф без обмеження). Так цифри і терміни не спотворюються.

## 2. Відкриті питання до тімліда

Пріоритет зверху вниз:

1. **Іспанія:** яку РК залишаємо — 19753 чи 19790? (у записі суперечність: 19753 то «кандидат на стоп», то «залишаємо»)
2. **Капи:** HU / SK / ES / IT — скільки? Іспанія: 30 (по CRM) чи до 100? Капа рахується в лідах чи в апрувах?
3. **Робоча зв'язка (крео 324 / 325 / 329 / 331):** на якому вона гео і на які гео її можна переносити?
4. **«TREP»:** що це, де брати крео, які «все спрацювали»?
5. **Унікалізація:** показати тімліду приклад своєї унікалізації — що саме з нею не так?
6. **Поріг ROI:** з якого реального ROI (з комісією) РК вважається «нормальною», а не «мікроплюсом»?
7. **Скільки чекати:** скільки спенду / днів давати новій РК до рішення?
8. **Бюджет на РК:** $40 — це стандарт для всіх гео?
9. **Словенія і Хорватія:** працювати далі чи поставити на паузу?
10. **Угорщина:** через скільки днів стабільного плюсу можна знову масштабувати?
11. **Кінцівка дзвінка:** що було після 30-ї хвилини (про змішування гео і тести)?
12. **Тести:** за яких умов і коли повертаємось до тестів нових гео / офферів?
13. **Апрув:** хто дає розбивку відхилень — менеджер партнерки чи рекл?

## 3. Що підготувати до наступного созвону

- Таблиця трекінгу за тиждень (файл 04) зі зведеними по гео / крео / кабінетах.
- Журнал рішень: що запускав, що вимикав, чому, який результат.
- ROI Угорщини по днях після созвону — чи повернувся плюс.
- Іспанія: ціна апрува по кожній РК.
- Результат масштабу робочої зв'язки на інших кабінетах.
- Відповіді на питання вище (або задати їх на созвоні).
